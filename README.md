# Broccoli Park — лендинг (RU / EN / UZ)

Чистый HTML + CSS + JS, без фреймворков и сборки.

```
index.html          разметка всех секций, SEO, JSON-LD, иконки (SVG-спрайт)
styles.css          стили (палитра — CSS-переменные в :root)
script.js           i18n, меню, анимации, слайдер, лайтбокс, форма
data/menu.js        меню: 281 позиция × 3 языка
i18n/ru|en|uz.json  все тексты интерфейса
i18n/bundle.js      копия словарей для открытия файла двойным кликом (file://)
tools/build-i18n.js пересобирает bundle.js из JSON
server.js           локальный сервер: сайт + отправка броней в Telegram
.env.example        образец настроек (токен бота)
```

## Запуск

- Локально с отправкой броней: `node server.js` → http://localhost:8080 (см. раздел «Бронирование»).
- Только посмотреть: двойной клик по index.html (тексты берутся из `i18n/bundle.js`, форма работает в запасном режиме).
- Хостинг: загрузить папку целиком на любой статический хостинг (Netlify, Vercel, GitHub Pages, обычный сервер).

## Как заменить фото

Все места под замену помечены в `index.html` комментарием `<!-- REPLACE: … -->`. Сейчас там:
фото из Яндекс Карт (снимки гостей — **нужно разрешение авторов**), фото блюд из Wolt и плейсхолдеры Unsplash.

1. Положите свои файлы в папку `img/` (например `img/hero.webp`), рекомендуем WebP, до 300 КБ; hero — от 1920 px по ширине.
2. Замените `src="…"` на `src="img/hero.webp"`. Атрибут `data-fallback` можно удалить (в нём через `|` перечислены запасные адреса).
3. Обновите `alt` — тексты alt лежат в `i18n/*.json` (ключи `gallery.a1…a10`, `about.f1.alt` и т. д.).
4. Затемнение поверх фото в hero и секции «Вечера» — переменная `--photo-overlay` в начале `styles.css` (сейчас `.75` = 75%).
5. Для адаптивности у фото есть `srcset` (несколько размеров): при замене на свои файлы либо удалите `srcset`, либо укажите свои размеры (`img/hero-800.webp 800w, img/hero-1600.webp 1600w`).
6. Картинка для соцсетей — `<meta property="og:image">` (1200×630).

Если картинка не загрузилась, сайт сам покажет запасное фото (`data-fallback`), а затем аккуратную заглушку.

## Как редактировать меню и цены

Откройте `data/menu.js`. Каждое блюдо — одна строка:

```js
{"id":"bp001","category":"breakfast","group":"breakfast",
 "name":{"ru":"…","en":"…","uz":"…"},"desc":{"ru":"…","en":"…","uz":"…"},
 "price":55000,"image":"https://…","tags":["hit"]}
```

- **Цена** — `price`, целое число в сумах без пробелов. Формат «55 000 сум / 55,000 UZS / 55 000 soʻm» сайт делает сам.
- **Фото** — `image`: ссылка или путь `img/menu/…jpg`; `null` — будет цветная заглушка категории с иконкой.
- **Бейджи** — `tags`: `"hit"` (Хит), `"pp"` (ПП), `"spicy"` (Остро), `"kids"` (Для детей).
- **Новое блюдо** — скопируйте строку и задайте уникальный `id`.
- **Таб** — `category` (список табов, их цвета и иконки — `MENU_CATEGORIES` вверху файла);
  `group` — подраздел внутри таба, его подпись — в `MENU_GROUPS`.
- В превью таба показываются 8 блюд: сначала с фото, потом хиты. Кнопка «Показать всё» раскрывает полный список по подразделам.
- Ланч-сеты в блоке «Завтраки и ланч-сеты» берутся из блюд с `"group":"lunch"`.

В узбекском тексте используйте букву **ʻ (U+02BB)**: oʻ, gʻ — не обычный апостроф.

## Как править тексты

Все тексты — в `i18n/ru.json`, `en.json`, `uz.json` (одинаковые ключи). В HTML элемент ссылается на ключ через
`data-i18n="key"` (текст) или `data-i18n-attr="placeholder:key;aria-label:key2"` (атрибуты).
Русский текст в самом `index.html` — это версия для поисковиков и для работы без JS; держите её в соответствии с `ru.json`.

После правки JSON выполните `node tools/build-i18n.js`, чтобы обновился `bundle.js` (нужен только для file://).

## Как добавить язык (например, казахский `kk`)

1. Скопируйте `i18n/en.json` → `i18n/kk.json` и переведите значения.
2. В `script.js` добавьте код в `var LANGS = ['ru', 'en', 'uz', 'kk'];`, в `formatPrice()` — формат валюты,
   в `applyI18n()` — язык карты (`kk_KZ`).
3. В `index.html` добавьте кнопку в оба переключателя: `<button class="lang__btn" type="button" data-lang="kk" aria-pressed="false" lang="kk">KK</button>`
   и строку `<link rel="alternate" hreflang="kk" href="https://broccolipark.uz/?lang=kk">`.
4. В `data/menu.js` добавьте ключ `"kk"` в `name`, `desc`, `MENU_CATEGORIES` и `MENU_GROUPS`
   (пока перевода нет — сайт покажет русский вариант).
5. `node tools/build-i18n.js`.

## Как работает язык

Порядок выбора: параметр `?lang=` → сохранённый выбор (localStorage) → язык браузера → русский.
При переключении меняются `<html lang>`, title, description, Open Graph, canonical, язык карты и адрес `?lang=`.

## Бронирование → Telegram-бот

Заявки с формы приходят в Telegram через `server.js` — маленький сервер без зависимостей (Node.js 14+).

**Запуск локально:**

1. В папке сайта должен быть файл `.env` (образец — `.env.example`):
   ```
   TELEGRAM_BOT_TOKEN=токен_от_BotFather
   TELEGRAM_CHAT_ID=
   ```
2. Откройте своего бота в Telegram и нажмите **«Старт»** (или добавьте бота в группу администраторов и напишите там любое сообщение).
3. В терминале, в папке сайта: `node server.js` (или `npm start`).
4. Откройте http://localhost:8080 — заявки с формы придут в чат.

При первом запуске сервер сам найдёт чат (группа в приоритете) и запишет `TELEGRAM_CHAT_ID` в `.env`.
Чтобы сменить чат — очистите `TELEGRAM_CHAT_ID` и перезапустите.

**Как устроено:** форма → `POST /api/booking` → сервер проверяет поля, отсекает спам (скрытое поле-ловушка,
не больше 5 заявок за 10 минут с одного IP) → `sendMessage` в Telegram. Гость видит «Заявка отправлена!».
Если сервер недоступен (например, сайт открыт двойным кликом), включается запасной вариант:
текст заявки копируется и предлагается открыть Telegram @broccoli_uz или позвонить.

**Безопасность:** токен хранится только в `.env`, сервер этот файл не отдаёт в браузер. Не публикуйте `.env`
(он уже в `.gitignore`). Если токен куда-то утёк — в @BotFather: `/revoke` → выпустить новый.

**На хостинге:** `server.js` запускается на любом VPS/хостинге с Node.js (`npm start`, переменные окружения
вместо `.env`). Для Netlify/Vercel логику из `handleBooking()` можно перенести в serverless-функцию и указать её
адрес в `BOOKING_ENDPOINT` в начале `script.js`.

## Проверено

Chromium, ширины 360 / 768 / 1024 / 1200 / 1280 / 1440 / 1920 px — без горизонтальной прокрутки, без ошибок в консоли.

## Страница ссылок `/broccoli_links/`

Отдельная страница-визитка для шапки Instagram/Telegram (как Taplink): обложка, логотип, статус «Открыто сейчас»
(по времени Ташкента), кнопки Меню · Локация · Instagram, затем Бронь, Позвонить, Telegram, Доставка, Сайт.
Всё в одном файле `broccoli_links/index.html` (стили и скрипт внутри), языки RU/EN/UZ — в объекте `DICT` в конце файла,
выбранный язык общий с основным сайтом. Фон — фото зала `broccoli_links/bg*` с затемнением 75% (переменная `--overlay` в начале файла), логотип — `logo.*`. Страница рассчитана на один экран телефона без прокрутки.
Ссылку добавить в Instagram: `https://broccolipark.uz/broccoli_links/`.
